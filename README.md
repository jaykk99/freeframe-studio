# FreeFrame Studio

Free AI creative studio — create characters, generate images, and turn them into motion clips. No sign-up, no credits.

- Images: [Pollinations.ai](https://pollinations.ai) free API (Flux / Turbo, ~1 image per 15s)
- Video: in-browser camera-move clips rendered with canvas + MediaRecorder (.mp4 on Safari, .webm on Chrome)
- Library: saved in your browser (localStorage)

Live: https://jaykk99.github.io/freeframe-studio/
